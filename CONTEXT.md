# Repository memory

Repository memory preserves project knowledge so future contributors and agents can continue work with its intent intact.

## Language

**Project intent**:
The accepted decisions, reasons, constraints, and scope that guide work on a project. Current implementation can diverge from intent; a divergence does not by itself revise the decision.

**Memory note**:
A selected piece of project knowledge retained from work, with enough context to distinguish an accepted decision, observation, proposal, or open question.

**Local history**:
The record retained in one contributor's working environment. Its presence alone does not make it available to teammates.

**Shared project knowledge**:
Durable knowledge available to contributors through the repository's normal sharing workflow. Its current accepted decisions have one authoritative home.

**Supersession**:
An explicit replacement of an earlier decision by a later one. Adding context or extending a decision does not necessarily supersede it.

**Memory summary**:
A compressed account of a group of notes, used to find relevant history. It may omit details and does not replace the original evidence.
